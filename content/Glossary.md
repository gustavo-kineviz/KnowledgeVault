This is a collection of important terms and concepts with clear definitions for quick reference and review.
## Retrograde Amnesia

In medicine: the **inability to form new memories** after a certain event or condition.

In LLMs: a metaphor for when the model "forgets" earlier conversation once the input exceeds its memory window.

## Applet

A small computer program designed to perform a specific task.

---

## Call to Action (CTA)

A clear directive that tells the audience what specific step to take next, typically placed at the end of presentations or content.

---

## CamelCase

A way of writing names where each word starts with a capital letter and no spaces are used.  
Common in JavaScript because spaces aren't allowed in variable names.

![[Pasted image 20250603113551.png]]

---

## Cliffhanger

A narrative technique that builds suspense by creating an unresolved situation, making the audience eager to know what happens next. Triggers dopamine release.

---

## Command Line Interface (CLI)

The text-based way to interact with your computer using typed commands, as opposed to a GUI. Terminal is macOS's CLI application.

---

## Directory/Folder

A container for files and other directories on your computer. In programming, understanding file structure is crucial for organizing projects and navigating codebases.

---

# ETL
Extract, Transform, Load. It's moving data from a place to another while changing its structure along the way. So like pulling data from a database, enrich it and put that data into a destination system. 
## GUI

Short for **Graphical User Interface** — a way to interact with software through icons, buttons, and visuals, instead of typing commands.

---

## Hook

The opening element of a story designed to immediately grab audience attention and create engagement. Often uses surprise, relatability, or intriguing questions.

---

## Lambda

In JavaScript, a **lambda** refers to an **arrow function** — a shorter way to define functions.

![[Pasted image 20250324164243.png]]

---

## LLM

A powerful type of AI (often based on the **Transformer** architecture) trained on massive amounts of text and code.  
It predicts the next word (or "token") to generate human-like text, answer questions, summarize, translate, or write code.  
It's a "black box" — it learns rules from data instead of being explicitly programmed.

---

## Markdown

A **lightweight markup language** for adding formatting to plain text.  
Used in `README` files, documentation, and blogs because it's easy to read and write.

---

## Path

The location of a file or folder on your computer, written as a series of folder names separated by slashes (e.g., `/Users/username/Documents`). Essential for navigating file systems and referencing files in code.

---

## Root Directory

The top-level directory of a file system, represented by `/` on Unix-like systems (Mac/Linux). Everything on your computer lives under the root directory.

---

## snake_case

A style where spaces are replaced with underscores (`_`) and all letters are lowercase.

## Version Control System

A tool that tracks and manages changes to files over time.  
Enables collaboration, rollback to previous versions, and conflict resolution.  
Examples: **Git, Subversion (SVN), Mercurial**.




# Relational data
Data organized into tables (also called **relations**) with rows and columns. Each row represents a record and each column an attribute - a two-dimensional structure.
